## 📋 О проекте

Это полное практическое руководство по TurboCNC 4.01 (Build 050312) — программе для управления станками с ЧПУ через LPT-порт.

Руководство создано на основе **18-летнего опыта работы с промышленным оборудованием** и включает:
- Установку и первый запуск
- Настройку осей, входов/выходов, шаговых двигателей
- Программирование на G-коде и M-коде
- Работу с переменными и выражениями
- Горячие клавиши и управление
- Безопасность работы
- **Разбор реальной программы** `LES2008.CNC` для изготовления изделий из проволоки

## 🎯 Для кого это руководство

- **Наладчики станков с ЧПУ**, которые хотят разобраться в TurboCNC
- **Владельцы гаражных мастерских**, купившие станок с ЧПУ

## 1. Общая информация

**TurboCNC 4.01** — профессиональная программа управления станками с ЧПУ.

### Основные возможности
- Управление до 8 осями
- Поддержка переменных и выражений
- Циклы и подпрограммы (M97/M98/M99)
- Работа с G-кодом и M-кодом
- Режимы: ручной (Jog), автоматический, MDI
- Компенсация люфта
- Рабочие смещения (G54-G59)

### Технические требования
- **ОС:** Windows 95/98/ME/2000/XP или DOS
- **Процессор:** 486 или выше (рекомендуется Pentium)
- **Память:** минимум 4 МБ RAM
- **LPT порт:** для подключения к станку
